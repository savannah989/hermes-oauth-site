Privacy Policy

Personal Google Workspace Integration (Hermes Agent OAuth client)

This policy describes how a personal, single-user Google Cloud project accesses Google user data. It applies to the Google account that authorized the project and to no one else.

1. Who processes your data

The account holder is the sole data controller. All processing occurs on the account holder’s own computer. No server, API, or third-party service receives, inspects, or stores any Google data.

2. What data is accessed and why

The OAuth client requests the following scopes. Each is used only for the purpose stated:

  • gmail.readonly — read messages so a requested search or summary can be produced
  • gmail.send — send a message only when explicitly instructed
  • gmail.modify — reply, label, and archive in reply to an explicit instruction
  • calendar — read events and create or edit events on request
  • drive — search, read, upload, download, share, and delete files on request
  • spreadsheets — read and write cell values on request
  • documents — read and create documents on request
  • contacts.readonly — read contacts to resolve a name to an email address

No scope is exercised for advertising, profiling, model training, advertising resale, or any purpose other than the operations above.

3. Where your data is stored

OAuth tokens are stored in the Hermes configuration directory on the same computer, in the local file google_token.json. This file never leaves that machine and is not transmitted to any external service. Retrieved Google content is content you asked for; anything written back to Google — a sent email, a created event, a new Drive file — goes only to your own Google account.

4. Sharing

No Google data is shared with, sold to, or rented to any third party. The only external transmission of Google data is to Google’s own API endpoints, that is, a request made to Google for the account you authorized.

5. Retention and deletion

Tokens persist for as long as authorization remains active. Access ends immediately when access is revoked at myaccount.google.com/permissions, and deleting the local token file removes the stored credential entirely.
