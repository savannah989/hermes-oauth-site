Personal Google Workspace Integration

Application information page — personal, single-user project

What this is. A private Google Cloud OAuth 2.0 project used to connect Hermes Agent to a single Google account, running entirely on one personal computer. This page exists to satisfy the OAuth consent-screen configuration in the Google Cloud console. No third party has access to any data.

What the integration can access

The following Google Workspace permissions are requested. No permission outside this list is used.

  • Gmail — read, send, and modify messages
  • Google Calendar — view and edit events
  • Google Drive — view, create, edit, share, and delete files
  • Google Sheets — view and edit spreadsheets
  • Google Docs — view and create documents
  • Contacts — read contact information

How your data is handled

  • All access happens locally on one personal computer.
  • Data is never sold, rented, or shared with third parties.
  • No analytics, tracking, or advertising technology is used.
  • Google data is used only to operate the features you directly request.
  • Access can be revoked at any time from your Google account permissions page.

Human review

This is a personal project with a single user, so the OAuth client is not submitted for Google verification. Every request to authorize will show Google’s standard “Google hasn’t verified this app” screen; choose Advanced → Go to (unsafe) to continue. Expect the consent screen to show a generic app name rather than a branded one, because branding is only displayed for verified apps.
